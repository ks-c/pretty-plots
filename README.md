# pretty-plots

It is a repository of plotting scripts with simple js and html. It could be launched easily on any platforms.

## single class violin plot

支持自动计算P值、自由拖拽显著性标记及全自定义样式的出版级小提琴图绘制工具。
A publication-level violin plot drawing tool that supports automatic P-value calculation, freely draggable significance markers, and fully customizable styles.
[Let's try](https://ks-c.github.io/pretty-plots/plots/violin-single-class.html)

## multiple centrality indices plot

支持多文件分组比对和“并排网格子图”排版的网络节点影响力分析绘图工具。
A plotting tool for network node influence analysis that supports multi-file group comparison and "side-by-side grid subplot" typesetting.
[Let's try](https://ks-c.github.io/pretty-plots/plots/node-centrality.html)
